# Nomos Ludens

### Technology for human agency.

**Empower, not replace.**

Independent tools for a more human internet.

[Principles](./EMPOWER_NOT_REPLACE.md) · [Kódice](https://github.com/NomosLudens/kodice) · [Book Composer](https://github.com/NomosLudens/book-composer) · [Kuan](https://github.com/NomosLudens/kuan) · [Aether Studio](https://github.com/NomosLudens/aether-studio) · [OmniTreco](https://github.com/NomosLudens/omnitreco-replicable) · [Héstia](https://github.com/NomosLudens/hestia-replicable)

## What we believe

Technology should expand human capability without making human judgment, authorship or control disappear.

AI may assist.  
Automation may execute.  
Systems may suggest.

**Human agency must remain legible.**

## Featured work

### Kódice

**Law, reading and reproducible data without giving up local control.**

Kódice combines a local-first EPUB/PDF/TXT reader with a reproducible Brazilian legal corpus, deterministic citation search, SQLite materialization and a public legal API.

Personal books and notes stay on the user's device by default; the legal corpus can be rebuilt and audited from declared sources.

[Explore Kódice →](https://github.com/NomosLudens/kodice) · [Live demo →](https://kodice.nomosludens.ia.br)

### Book Composer

**Automate repetition. Preserve editorial judgment.**

Book Composer is a local-first visual editor for structured book composition, geometric preflight and deterministic PDF generation.

It was extracted from the real production of *KALLISTIS — Manual do Mundo*: the originating book remains a stress test, while the engine is deliberately project-independent.

[Explore Book Composer →](https://github.com/NomosLudens/book-composer)

### Kuan

**Automation can assist. The Guardian decides.**

Kuan supports commercial operations with AI-assisted automation while keeping final human authority explicit.

[Explore Kuan →](https://github.com/NomosLudens/kuan)

### Aether Studio

**A local engineering cockpit for visible, human-supervised AI work.**

Aether brings technical conversation, Klio-inspired PromptForge, local SQLite persistence and optional Codex, Antigravity and OpenRig execution into one interface. It keeps delivery and task completion as separate claims, and requires the user to choose and confirm an executor.

The project is experimental and runs on the developer's machine; provider integrations depend on locally installed tools and authentication.

[Explore Aether Studio →](https://github.com/NomosLudens/aether-studio)

### OmniTreco

**Seu navegador ganhou poderes.**

A local-first, browser-first multi-tool that turns files, sensors and nearby devices into capabilities in the user's hands.

> If the browser can do it, the server does not touch the file.

[Explore OmniTreco →](https://github.com/NomosLudens/omnitreco-replicable)

### Héstia

**Observe real systems without turning observability into unrestricted control.**

Héstia is a console + station-agent architecture for Linux observability and bounded operational actions. It keeps unavailable state explicit and treats real host validation as stronger evidence than a green dashboard.

## Research / Experimental Systems

### Flynn

**Persistent neuro-synthetic systems, documented without overstating the evidence.**

Flynn is an archived experimental research project around a continuous loop of world → sensory transduction → LIF brain → descending readout → synthetic body → world.

The repository preserves recovered code, causal traces, visual evidence and the isolated E01 replication kit. The original resident runtime is no longer available, and the archive explicitly distinguishes preserved evidence from claims that were never proven.

[Explore Flynn →](https://github.com/NomosLudens/flynn) · [Replicability limits →](https://github.com/NomosLudens/flynn/blob/master/REPLICABILITY.md)

## Principles in practice

- **Human authority** — it should be clear who decides, approves, rejects and overrides.
- **Capability over substitution** — remove friction before removing understanding.
- **Local-first when possible** — keep computation and data with the user when centralization adds no real value.
- **Verifiable automation** — automated actions should be bounded, observable and contestable.
- **Reality over simulated success** — plausible output is not proof.
